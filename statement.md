## Problem Statement
Developing decision-making logic and state-management in a constrained environment through a gamified Python application.

## Scope of the Project
The game covers a 7-day simulation. It tracks variables such as health, resources, and inventory across multiple modules. The project focuses on text-based input validation, loop iterations, and modular function calling.

## Target Users
- Gamers looking for a retro text-adventure experience.
- Python learners studying OOP, control flow, and code structuring.

## High-level Features
1. **Game Engine Module:** Manages loops and state progression.
2. **Player Object:** Encapsulates inventory and damage calculations.
3. **Location Module:** Handles branching logic based on user choices.
