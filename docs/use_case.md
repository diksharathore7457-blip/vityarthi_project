## Primary Actor

**Player** — interacts with the console and controls all survival decisions.

## Main Use Cases

- Start game
- Explore
- Search for supplies
- Fight zombies
- Escape
- Select weapons
- Use medkits
- Monitor health/resources
- Survive seven days
- Receive victory/game-over result
