# Project Statement

## Project Title
Zombie Survival Simulator

## Problem Statement

A survival situation requires a person to continuously make decisions while managing limited resources. This project models that idea as an interactive console-based zombie survival simulation.

The player is placed in a fictional city affected by a zombie outbreak. The player has limited health, food, water and medical supplies and must make decisions about exploration, rest and combat. Different choices produce different consequences.

## Scope

The project covers:

- Seven-day survival gameplay
- Resource management
- Location-based exploration
- Weapon and ammunition management
- Zombie combat
- Medkit usage
- Branching choices
- Victory and game-over states

The current version is a local console application. It does not use a database, internet connection, external API or graphical interface.

## Target Users

- Students learning Python
- Beginners interested in game programming
- Users who want a short text-based survival game
- Demonstrators evaluating basic programming concepts

## High-Level Features

1. Seven-day survival progression
2. Multiple exploration locations
3. Resource management
4. Weapon inventory
5. Ammunition tracking
6. Combat decisions
7. Medkit system
8. Multiple consequences
9. Game-over condition
10. Seven-day rescue ending

## Input

The program receives keyboard input for:

- Starting/exiting the game
- Selecting daily actions
- Selecting exploration options
- Choosing whether to trust/investigate
- Choosing fight/escape
- Selecting weapons
- Choosing whether to use medkits

## Output

The program displays:

- Story events
- Survivor status
- Menus
- ASCII art
- Resource changes
- Combat outcomes
- Victory/game-over messages
