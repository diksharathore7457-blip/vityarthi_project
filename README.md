# Zombie Survival - Text Adventure

## Overview
A terminal-based survival game where the player must manage resources (health, food, water) and make strategic choices to survive a 7-day zombie apocalypse until a rescue helicopter arrives.

## Features
- **Resource Management:** Balance food, water, and health daily.
- **Dynamic Encounters:** Explore buildings, gas stations, and supermarkets.
- **Combat System:** Fight using bare hands or weapons (if found).
- **Object-Oriented Design:** Modular codebase with clean separation of concerns.

## Technologies Used
- Python 3.x
- Built-in libraries (`time`)

## Steps to install & run
1. Clone the repository.
2. Open a terminal in the project folder.
3. Run `python main.py`

## Instructions for testing
Enter numeric inputs (`1-5`) when prompted on the menu, and `y/n` for dialogue boxes. Intentionally run out of food/water to test the starvation mechanics.
