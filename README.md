# 🧟 Zombie Survival - Text Adventure Simulation

## 📖 Overview
The "Zombie Survival" project is an immersive, terminal-based interactive simulation game. Players are thrust into a post-apocalyptic world where they must survive for 7 days until a rescue helicopter arrives. The game tests strategic decision-making by forcing players to manage finite resources (food, water, health, and medical kits) while navigating through various high-risk environments.

## ✨ Features
- **Resource Management:** Balance food, water, and health daily. Failure to maintain food and water results in starvation and dehydration penalties.
- **Dynamic Encounters:** Explore various locations such as abandoned buildings, gas stations, and supermarkets, each with unique risks and rewards.
- **Combat System:** Fight roaming zombies using bare hands or scavenged weapons (Pistol, Shotgun, Baseball Bat).
- **Inventory System:** Track medical kits, weapons, and ammunition. 
- **Object-Oriented Design:** The codebase is heavily modularized using Object-Oriented Programming (OOP), ensuring clean state management and scalability.

## 🛠️ Technologies / Tools Used
- **Language:** Python 3.x
- **Libraries:** Built-in libraries (`time` for pacing text output)
- **Architecture:** Modular OOP (Object-Oriented Programming)

## 🧪 Instructions for Testing
- **Menu Navigation:** Enter numeric inputs (`1-5`) when prompted on the main menu.
- **Input Validation:** Try entering letters or out-of-bounds numbers to test the error handling. The game will safely reject invalid inputs without crashing.
- **Resource Testing:** Intentionally avoid scavenging for food and water to observe the starvation/dehydration mechanics deduct health at the end of the day.
- **Combat Testing:** Engage in combat without weapons to see heavy damage, then find a weapon in the gas station and test combat again to see damage reduction.
